# Casino Bot (Telegram)

Толық казино-бот: валюта, админ-панель, ойындар.

## Ойындар
- **Краш / Ракета** — `краш [ставка]` немесе `кр [ставка]`
- **21 очко** — `21 [ставка]` / `бд [ставка]`
- **Кубы** — `кубы [ставка] [1-6]` (×12)
- **Дуэль** — хабарламаға жауап ретінде `дуэль [ставка]`
- **Казино** — `казик [ставка]` / `казино [ставка]`
- **Боулинг** — `боулинг [ставка] [1-6]` (×10)
- **Орел/Решка** — `орел [ставка]` / `решка [ставка]`

## Командалар
- `/start` — бастау
- `баланс` — балансты қарау
- `мои игры` — соңғы 40 ойын
- `/admin` — әкімші панелі

## Әкімші командалары
- `/give [user_id] [сумма]` — валюта беру
- `/take [user_id] [сумма]` — валюта алу
- `/setbal [user_id] [сумма]` — балансты орнату
- `/makeadmin [user_id]` — админ ету (тек басты админ)
- `/deladmin [user_id]` — админді алу
- `/bal [user_id]` — балансты қарау

## Орнату

1. Python 3.10+ орнатыңыз
2. Тәуелділіктерді орнатыңыз:
   ```bash
   pip install -r requirements.txt
   ```
3. `.env` файлын жасаңыз (`.env.example` үлгісін көшіріңіз):
   ```env
   BOT_TOKEN=сіздің_бот_токеніңіз
   MAIN_ADMIN_ID=сіздің_telegram_id
   ```
4. Ботты іске қосыңыз:
   ```bash
   python bot.py
   ```
